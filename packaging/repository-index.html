Thallium Store

The native Qt 6 build of Thallium Store: apt or pacman, the AUR, Flathub, GitHub releases and AppImages in one place.

Install — no sudo

curl -fsSL https://store-qt.thallium81.dev/install.sh | sh

Installs a self-contained build into ~/.local, with its own Qt. Works on any x86_64 distro with glibc 2.36 or newer — Debian 12+, Ubuntu 23.04+, Arch, Fedora 37+. Run it again to update; add -s -- --uninstall to remove it.

Install with your package manager

curl -fsSL https://store-qt.thallium81.dev/install.sh | sh -s -- --system

Adds a signed APT source (Debian 12, Debian 13, Ubuntu 24.04) or pacman repository (Arch) so the store updates with the system. It asks for your password itself.
