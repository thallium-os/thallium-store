You are here

Quickshell

The build Thallium 81 ships. Needs Quickshell installed. Debian 13 (trixie), amd64.

curl -fsSL https://store.thallium81.dev/install.sh | sudo sh
Anywhere else

Native Qt 6

No Quickshell needed. Debian 12, Debian 13 and Ubuntu 24.04, amd64.

curl -fsSL https://store-qt.thallium81.dev/install.sh | sudo sh
On Thallium 81 the store is already installed and updates with the OS — there is nothing to add.

The installer checks the archive key against a pinned SHA-256, adds one APT source, and pins it so it can only ever supply thallium-store — never replace other system packages.
